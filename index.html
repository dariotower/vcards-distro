Firma Distrocuyo

Pegá una línea o varias líneas con los datos. Los campos se completan solos, el QR se genera automáticamente y el nombre ahora puede pasar a dos líneas para sostener mejor la jerarquía. Si pegás varios contactos, también podés descargar el lote.

Datos del contacto

Acepta una línea, varias líneas o un lote. Cada línea puede venir con este formato: «Nombre Apellido: Cargo - teléfono - mail».

En lote, Chrome puede pedir permiso para múltiples descargas. Si aparece el aviso, permitilas una vez y sigue.

Vista previa

La vista previa y el sitio son responsive. La descarga sale a 1920 × 1080 px.

Si corregís algo a mano, la vista y el QR se actualizan solos. En nombres largos, ahora se mantiene una sola línea y ajusta el cuerpo tipográfico sin partir el nombre.
